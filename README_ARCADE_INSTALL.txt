Project 67 Arcade
=================

To play:

1. Unzip the downloaded file.
2. Open index.html in a browser.
3. Pick a card from the launcher.

Notes:

- Progress and recently played history are saved only in the browser on that device.
- Pulse Deck plays audio files chosen from your own computer.
- Super Cross Hair is a separate macOS app and is not included in this browser-game bundle.
